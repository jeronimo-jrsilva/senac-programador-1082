## 🛠️ Como utilizar no GitHub Codespaces

1. Clique no botão verde **Code** no topo da página.
2. Selecione a aba **Codespaces** e clique em **Create codespace on main**.
3. O ambiente VS Code será aberto diretamente no seu navegador, com Node.js e terminal configurados para execução dos códigos.
4. Para executar os arquivos práticos no terminal do Codespaces:
   ```bash
   node 02_Console_JS/exercicios_console.js
   ```
